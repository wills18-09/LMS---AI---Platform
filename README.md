# LMS AI Platform 🚀

An AI-powered Learning Management System designed to deliver a complete digital learning experience with course management, video learning, assessments, achievements, and role-based workflows.

The platform provides dedicated experiences for students, instructors, and administrators with a scalable full-stack architecture.

## Authentication & Authorization

- User registration and login
- JWT-based authentication
- Refresh token support
- Protected routes
- Role-based access control

- Admin
